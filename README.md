# easy_test

## Требования

* Python 3.x
* Библиотека `requests`

# Инструкция по запуску

## 1. Установите зависимость:
   ```bash
   pip install requests
   ```
## 2. Запустите скрипт в терминале:
```bash
python main.py
```

# Единицы измерения

## Объем данных: Мегабайты (МБ), где 1 МБ = 1048576 байт.

## Время: Секунды (с).

## Скорость: Мегабайты в секунду (МБ/с).
